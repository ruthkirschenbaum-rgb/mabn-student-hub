MABN STUDENT HUB WEBSITE

This is a self-contained static website for the Queens College MABN Student Hub.

FILES
- index.html: the webpage
- styles.css: design and responsive layout
- brand.css: MABN header and attribution styling
- app.js: opportunity listings, search, filters, and calendar downloads
- assets/: Queens College and CUNY logo image

TO PUBLISH
Upload all website files and the assets folder together to the appropriate web folder.
The web address should point to index.html. Keep the filenames unchanged.

TO UPDATE OPPORTUNITIES
Open app.js in a text or code editor. Near the top is the "opportunities" list.
Each listing contains its date, title, organizer, type, location, amount, and official URL.

IMPORTANT
Opportunity details may change. Confirm dates with the official organizer when updating the page.
